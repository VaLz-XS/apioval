Dokumentasi

Semua endpoint pakai method GET kecuali register.

GET/api/tiktok

Parameter: url, apikey (atau header x-api-key)

/api/tiktok?url=LINK_TIKTOK&apikey=ov_xxx
{
  "ok": true,
  "title": "...",
  "video": "https://...",
  "music": "https://...",
  "plan": "free",
  "limit": 100,
  "remaining": 99
}
GET/api/usage 
/api/usage?apikey=ov_xxx
POST/api/register

Body JSON: {"name":"opsional"}. Maks 3 key per hari per IP.

Contoh di bot (Node.js) 
const r = await fetch(
  `https://apioval.vercel.app/api/tiktok?url=${encodeURIComponent(link)}&apikey=KEY_LU`
);
const d = await r.json();
if (d.ok) { /* kirim d.video */ }
else { /* d.error */ }
Kode error 
401  API key kosong / tidak valid
400  parameter url kosong
429  limit harian habis
502  gagal ambil video
