Coba langsung pakai API key lu

Semua endpoint di bawah bisa dicoba di sini. Buat API key dulu di Beranda kalau belum punya.

Dokumentasi

Semua endpoint pakai GET kecuali register
GET /api/tiktok

Parameter: url, apikey (atau header x-api-key)

/api/tiktok?url=LINK_TIKTOK&apikey=ov_xxx

Response video:

{
  "ok": true,
  "type": "video",
  "title": "...",
  "author": "...",
  "video": "https://...",
  "images": [],
  "music": "https://... (mp3)",
  "plan": "free",
  "limit": 100,
  "remaining": 99
}

Response foto (slideshow): type = "image", video kosong, images berisi daftar link foto.

GET /api/brat

Parameter: text, apikey. Opsional: format (png/webp), bg, color (hex tanpa #)

/api/brat?text=halo+dunia&apikey=ov_xxx
/api/brat?text=halo&format=webp&apikey=ov_xxx

Response berupa gambar 512x512.

GET /api/usage
/api/usage?apikey=ov_xxx
POST /api/register

Body JSON, maks 3 key per hari per IP.

{"name":"opsional"}
